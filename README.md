# 🏥 MediVault: Decentralized Medical Records System

## 🌟 Overview
MediVault is a blockchain-based medical records system that puts patients in control of their health data. Built on Stacks blockchain using Clarity smart contracts, it enables secure storage and sharing of medical records between patients and healthcare providers.

## ✨ Features
- 👤 Patient registration and profile management
- 👨‍⚕️ Doctor verification system
- 📝 Secure medical records creation
- 🔐 Granular access control
- 🏃‍♂️ Real-time record updates

## 🚀 Getting Started

### Prerequisites
- Clarinet
- Stacks wallet
- Node.js

### Contract Functions

#### For Patients
1. `register-patient`: Create a new patient profile
2. `grant-access`: Give a doctor access to records
3. `revoke-access`: Remove a doctor's access
4. `get-patient-info`: View patient information

#### For Doctors
1. `register-doctor`: Create a doctor profile
2. `add-medical-record`: Add a new medical record
3. `get-medical-record`: View patient records
4. `get-doctor-info`: View doctor information

## 🔒 Security
- Patient data is stored securely on-chain
- Access control mechanisms ensure data privacy
- Only verified doctors can create medical records
